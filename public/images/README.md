# Portfolio Images

Drop your images into the correct folders with the **exact filenames** below. The website will automatically pick them up.

---

## Profile (`/images/profile/`)

| Filename | Used on | Recommended size |
|---|---|---|
| `profile.jpg` | About page — main photo | 800×1000px (portrait) |
| `avatar.jpg` | (optional) Navigation or favicon | 256×256px (square) |

## Tips

- Use `.jpg` or `.webp` for photos (smaller file size)
- Use `.png` if you need transparency
- Keep file sizes under 500KB for fast loading
- Aspect ratio 3:2 works best for project cards
